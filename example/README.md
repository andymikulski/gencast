# Example Usage

This directory contains an example of how to use GenCast in a TypeScript project.

## Files

- `User.ts` - Contains interface definitions
- `User.gen.ts` - Generated casting functions (created by running `gencast`)
- `example.ts` - Example usage of the casting functions

## Running the Example

1. Run GenCast to generate the casting functions:
   ```bash
   npx gencast
   ```

2. The `User.gen.ts` file will be generated with casting functions

3. Use the functions in your code as shown in `example.ts`
